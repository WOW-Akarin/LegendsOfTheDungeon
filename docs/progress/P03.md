## 要实现的 Gate

1. 显式真实 ProjectReference 白名单。
2. Domain 不得引用 Platform Adapter / Host。
3. Module A 不得引用 Module B 的 Infrastructure / Internal。
4. Modules 不得引用 Hosts。
5. 生产项目 ProjectReference 图必须无环。
6. 生产公共 API 不得暴露被禁止的实现项目类型。
7. `InternalsVisibleTo` 只允许显式白名单。
8. 跨模块高 fan-in 依赖中心必须显式完成职责审查；自动判断不依赖 Common/Utils/Manager 等名字。

## 测试原则

- 每条规则都包含合法 fixture 和故意违规 fixture。
- 真实生产项目图直接从 Solution/csproj/编译 Assembly 读取，不靠文档声称。
- 违规 fixture 保存在测试模型中，不向生产项目加入非法引用。
- 类名、命名空间名和关键词只允许作为人工定位信息，不作为规则成立的唯一依据。
- P03 不创建没有调用方的生产项目。
