## 目标与设计边界

本阶段提供通用有界 WorkQueue、关键回执预留的双车道 Mailbox、受逻辑 Tick 推进的 Scheduler、有限 worker 的 BackgroundWorker。定义线程安全队列满拒绝、关键回执独立容量、普通任务错误隔离、取消、关闭顺序及超时未完成清单。Platform.Concurrency 为技术层，不执行或拥有 World/Entity 状态写入；P18 WorldExecutor 以后接纳并负责唯一合法写上下文。

## 计划实现

1. 独立无第三方依赖的 Platform.Concurrency Assembly；同步 Solution/P03 manifest/Unit 项目与 lock files。
2. 两车道 Mailbox：普通/关键容量分别固定；关键优先但以 burst quota 防普通请求饥饿；关闭时可继续 drain 已接纳项。
3. WorkQueue：固定容量、显式 Busy / Closed / Duplicate 结果，任务 ID 的 queued/running 记录与完成清理。
4. BackgroundWorker：worker 数量固定、逐项隔离异常/取消；优雅关闭停止接纳后 drain；超时发送取消并返回 queued/running 的未完成清单。
5. Scheduler：逻辑 Tick 到期顺序稳定、队列有界、可取消，单 Tick 最大派发数有限；不创建每实体系统 Timer。
6. Unit + 真实多线程并发探针，包括队列压力、关键容量、饥饿、异常隔离、取消与关闭超时。
