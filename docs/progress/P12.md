## 实现范围与边界

提供独立 Platform.Concurrency Assembly（无第三方包，无游戏 Domain 依赖）。技术层负责有界队列、逻辑调度和后台异步执行，不拥有 World/Entity 可变状态，也不能生成 WorldExecutor 写入租约。P18 才实现 WorldMailbox、Epoch/Generation 身份复核与世界唯一写上下文。

- BoundedMailbox<T>：Normal/Critical 两个独立固定容量；关键 DB 回执与控制请求有预留容量；FIFO；满车道 Busy，关闭 Closed；跨 Drain 维护关键消息 burst 配额以防普通消息饥饿。
- LogicalScheduler<T>：固定最大积压、按 DueTick + 单调接纳编号排序，Cancel 立即释放容量；DrainDue 单轮预算；不创建系统 Timer、不直接执行世界写。
- BoundedWorkChannel：基于 bounded System.Threading.Channels；Offer 提供 Accepted/Busy/Closed/Duplicate；跟踪 Queued/Running/Abandoned 任务 ID，不静默丢弃已接纳任务。
- BackgroundWorkerPool：固定 Worker 数，逐项隔离异常、支持取消；有界脱敏失败历史；ShutdownAsync 先停止接纳，再等待排空，超时发取消并报告未完成列表，绝不将 Accepted 当作 Completed；DisposeAsync 不等待不配合取消的在途任务，放弃未执行队列回调并保留 Abandoned ID，CTS 于 Worker 真正退出后释放。
- 任务动作不允许直接持有或修改 World 可变状态；应将完成回执经未来的 WorldMailbox 送回 WorldExecutor。
