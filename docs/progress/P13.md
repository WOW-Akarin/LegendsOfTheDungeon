## 已实现范围

- 独立 `Platform.Networking` Assembly，依赖仅为 `Security.Contracts`（传递依赖 Kernel），不依赖 Domain、Runtime 或 Host。已同步 .slnx、P03 生产白名单、所有受影响 NuGet lock files。
- `IFrameTransport` 可插拔 Port；`FramedStreamTransport` 在双向 Stream 运行单接收者、单写入者、多生产者有界发送队列；`TcpLoopbackConnector` 只允许本机连接，`TcpLoopbackEndpoint` 仅监听 127.0.0.1，有限 backlog、唯一 Accept。
- 通用网络帧 v1：**uint32 大端长度前缀 + 非空 payload**。不包含 WoW Opcode、WorldPacket、客户端 3.3.5a、压缩/加密或领域命令。
- 单帧硬上限 1 MiB；整帧读取超时硬上限 30 秒，超长报头在分配 payload 前拒绝，慢速滴入不能延长总截止；帧内断线明确 Truncated，帧边界 EOF 则为正常结束。
- 出站等待缓冲双预算：最多 256 帧、4 MiB payload；OfferSend 即刻返回 Accepted/Busy/Closed/RateLimited，成功时复制数据快照，单写循环按序发帧。入站/出站使用独立的 1000ms 固定窗口帧数/字节限流。
- Graceful Stop：先停接纳并有限期排空；超时/写失败标记 DeliveryUnknown、报告未发队列和完整写入计数；DisposeAsync 取消 I/O 并释放连接资源，不等待无取消能力的自定义 Stream；本地写入不等同远端确认。
- 生产安全边界：`NetworkIngressGate` 经 `IIdentityBindingPort` → `ProductionIdentityGuard` → `ICommandAuthorizationPort`；当前无生产身份签发者，默认全部拒绝。传输不持有任何 World 写入回调；不信任网络 ActorId，真实入口仍待 P18/P27/P60/P61。

## 四视角自审结论

1. **功能**：协议在 TCP 无消息边界语义下显式组帧；断线、取消、超长、背压/限流/慢客户端、非配合取消写均有负向验证。
2. **所有权和架构**：技术传输层仅暴露字节帧和身份核验结果，不调用 WorldExecutor，也不能授予执行租约。P03 生产依赖白名单与独立 Assembly 限定边界；无万能 Service Locator。
3. **失败与恢复**：报头长度在内存分配之前受限，整个帧受一个计时预算约束；排队和在途写保守报告，失败不假称对端已确认；敏感凭证不进入网络错误文本。未来的世界与持久化端需按 CommandId 进行幂等恢复。
4. **可复现**：首次失败 #90–#93 已记录、修复从不弱化 Analyzer；#94–#99 真实 Linux TCP 与 PostgreSQL 全链路连续通过。10 项 Loopback 为本机真实 Socket（其中一项另用阻塞 Stream 注入纯技术故障），并非仅接口 mock。

**必需未解决实现项：0**。独立 REVIEW HEAD run #100 三 Job 全绿，满足正式 ACCEPTED；正式 ACCEPTED HEAD run #101 的三 Job CI 已完整 SUCCESS。

## 保留限制 / 后续归属

- 无生产认证/会话签发、TLS、公网监听、真实 ServerHost、连接全局配额、WorldEpoch/Generation/ActorId 绑定或 WorldExecutor；P13 **不能**用作未授权公网游戏命令入口。
- 固定窗口限制可能在时间窗口边界出现双倍瞬时突发；公网下的平滑限流、连接总预算与 DoS 策略须由 P60/P64/Host 再核验。
- 对端关闭/超时期间的本地成功 Write 不证明远端已接收或业务持久提交；P11/P65 的幂等账本和 P18 世界回执留待真实业务集成。
- 尚无加密/TLS、压缩、完整序列化协议、广域网络/公网威胁测试或 P64 性能验收。本阶段只承诺实际 TCP Loopback 的技术可靠性。
- 不拷贝/改写上游 AzerothCore 代码；WoW 专用协议显式排除。AC 对照路径不适用本通用帧设计。
