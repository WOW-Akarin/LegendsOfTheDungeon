## 边界与交付计划

1. 技术层实现可替换流式传输 Port、真实 TcpClient Adapter、基于大端 uint32 长度前缀的通用二进制帧，限制长度与整体读取耗时。无 WoW Opcode、WorldPacket、3.3.5a。
2. 入站有限读缓冲（严格最大 payload、读超时，EOF 与截断区分），出站固定容量/字节预算、有界背压和单写线程串行帧，断开与关闭释放资源。
3. 无需真实账户、ServerHost 或 WorldExecutor 的 Loopback 验证：真实 TCP 半包/粘包、非法长度、慢连接、慢消费者/满队列、限流、断线释放、可靠关闭。
4. 生产入口安全维持默认拒绝：无 P60 生产认证 Adapter 不转发世界写。使用 P60.F 的安全接口验证认证+授权，独立负例保证 LocalTest/无身份不能通过。
5. 依照 P03 生产 Assembly 白名单与 Solution/lockfiles 更新，CI 使用真实 Linux loopback probe。
6. 实现 CI → 四视角审查 → 独立 REVIEW HEAD CI → ACCEPTED HEAD CI，保留失败诊断与恢复步骤。

## 恢复风险

Network.Transport 不负责主体身份签发、不接受来自网络的可信 ActorId、不执行 World 写入、不提供 Host。真实公网监听/认证/命令入世界的接线必须在后续 P18/P27/P61 与 P60 完整安全阶段验证。本阶段仅在本机 127.0.0.1 完成 TCP 集成探针；不把真实网络 Loopback 验证等同公网威胁模型或性能 P64。
