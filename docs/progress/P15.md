## 范围冻结

- 静态数据基础只认识通用 Schema、字段类型、版本、规范化值、只读索引，不拥有 Ability/Item/Entity 业务定义；未来各领域提供自身 Schema。
- **P15.J**：严格 JSON→通用中立行→规范化→固定内容 Hash→冻结 Catalog。错误定位到 JSON 文档/记录索引/字段。
- **P15.S**：真实 PostgreSQL SQL 技术来源 Adapter，固定表名、参数化 SELECT、有限结果集；将 SQL 数据转成相同中立行、使用相同冻结/Hash 路径。测试数据库提供临时技术结构，不引入游戏表。
- 版本化 Schema、DataVersion 与内容 Hash 支持可复现构建。P16 才实现跨 Catalog 引用、循环验证与 Reload 原子切换，不提前声称本阶段包含完整 P16。
- 明确最大文档/记录/字段尺寸、重复 ID/字段拒绝、未知字段拒绝，出错不发布不完整 Catalog，不依赖 DBC。
- 实现、真实 PostgreSQL 集成、Unit、架构白名单、CI 后进入 REVIEW 与独立验收。
