## 实现边界

- Runtime.Abstractions 定义 `IWorldWriteContext` 和同步 `IWorldAction`、不依赖 Platform。
- 新 `Platform.WorldExecution` 使用 P12 `BoundedMailbox` 两条独立容量车道；每世界执行器实例唯一拥有正在执行的同步写入 scope，限制容量并记录 stale/busy/fault。
- 仅在执行同步回调时生成有效执行租约：匹配 WorldId/Epoch/EntityGeneration、当前逻辑 scope、执行线程以及有效运行序列；Task.Run 传播 AsyncLocal 也不具写权限。非同步回调不得跨 await 持有写入租约。
- 外部命令遵循 P60.F `ProductionIdentityGuard` + `ICommandAuthorizationPort`，接纳时和执行前二次验证，默认拒绝；生产身份发行器尚不存在。内部可信生产者为组合根显式保管的端口，不以网络接入自动等同可信。
- 外部 DB/Network/Worker 只能返回携带由 World 有效上下文发出的 opaque 票据的不可变回复，经关键 Mailbox 再次核验 WorldEpoch、EntityGeneration、请求序号与是否重复；禁止 worker 直接获得任何世界写租约。
- 生命周期仅追踪技术版本标记，真实 P17 Entity/WorldInstance 状态所有权不提前实装。
