## 交付范围

- 在 `Runtime.Abstractions` 定义同步 `IWorldAction`、`IWorldWriteContext` 和 `IWorldReplyTicket`；新增独立 `Platform.WorldExecution` 生产 Assembly，复用 P12 `BoundedMailbox` 和 P60.F `Security.Contracts`，并完成 Solution/P03 manifest/锁图。
- `WorldExecutor` 每世界拥有同一时刻唯一的同步 Scope 和 RunBatch 排它租约；`Demand` 校验**领域原生归属** WorldId、Epoch、EntityId、Generation。Task.Run 虽继承 AsyncLocal 也无法通过 Scope + 实际线程检查，完成回调后 Scope 失效。
- 双车道有限队列，普通洪流不吞占关键回执容量，关键消息有限 burst 也不饿死普通。可信 Producer 只能将回执再入队，不能直接写世界。
- 票据仅由有效世界 Scope 签发，绑定 owner/world/epoch/entity/generation/单调 requestSequence；旧/重复/伪造、实体退休或新代际、更新 Epoch 均无效；执行前再次检查。授权 P60.F 接纳前和执行前重复检验，空/LocalTest/默认授权全部 Denied。
- 意外领域异常 -> Faulted、封闭新输入、保留尚未执行队列/部分写入未知结果，不能伪装全回滚。关闭后已接纳的消息可按预算排空。
- 仅完成技术世界写 Guard；没有真实可写 Entity/WorldInstance Registry、生产身份签发与 Host，不声称 P17/P19/P60 完成。
