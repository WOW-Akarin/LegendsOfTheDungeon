## 交付和边界

1. `WorldSpawnRegistry`：固定 SpawnKey、EntityId、Generation、Status、Checkpoint；不复刻 P17/P20 可写实体或 Transform。
2. `RespawnTimer`：P19 Timers Phase 中调用 `LogicalTimer.Start`，FakeClock 到期重生，旧代际退休后新 Generation 自增。
3. `LinkedRespawn`：只在存在的静态 Key 中关联，自环/长环检测，父节点先于子节点生成；父未 Active 时子跳过。
4. `DynamicSpawn`：可信 P18 同步 Scope 下一时创建，已卸载 Grid 拒绝，退休后不自动重生。
5. Grid 加载/卸载：无隐式 Activate、重复加载幂等、外来实体 Occupied 阻断、受管实体退休 + P20 空 Cell 卸载。
6. Checkpoint 恢复：已确认实例不匹配 P17 Active 时 `RecoveryHold`，不重复创造副本；保存绝对到期 Tick，显式可信完整身份核对才能解除 Hold。
