## 算法与随机流约定

1. PRNG 固定为 `xoshiro256**`，算法 ID `xoshiro256starstar`，版本 `1`。
2. 64-bit Seed 使用固定 SplitMix64 初始化四个 64-bit 状态字。
3. `RandomState` 导出算法 ID、版本和四个状态字；恢复时版本必须匹配，且全零状态拒绝。
4. 有界整数抽样使用 rejection sampling，避免简单取模偏差。
5. `Probability` 接受 decimal `[0,1]`，量化到 `2^-32` 固定精度，使用 round-to-nearest-even；区间外拒绝，不 clamp。
6. 概率 0/1 为确定结果且**不消耗随机状态**；内部概率消耗一次有界随机样本。
7. `WeightedOption<T>` 权重必须为正 `UInt64`；0 权重、空集合、总权重溢出拒绝。
8. Combat/Loot/AI 使用 `RandomStreamKind` 的稳定显式 ID + 固定 salt 派生子 Seed；禁止运行时 `GetHashCode` / string hash 派生。
9. 后续模块通过 `IRandom` 注入，不依赖 `DeterministicRandom` 具体类型。

## 实现落库

- `RandomState.cs`：算法 ID/版本 + 四状态字快照，default 未初始化。
- `Random.cs`：`IRandom` 与 xoshiro256** v1 `DeterministicRandom`，SplitMix64 Seed 初始化、状态恢复、无偏有界抽样。
- `Probability.cs`：decimal [0,1] → 2^-32 nearest-even 量化；0/1 不消耗随机状态。
- `WeightedSelector.cs`：严格正 UInt64 权重、快照选择、空/default/总权重溢出防护。
- `RandomStreams.cs`：Combat/Loot/AI 显式稳定 ID 与固定 salt 派生独立 Seed。
- `RandomTests.cs`：算法 known vector、同 Seed、状态恢复、概率/权重边界、稳定流隔离。
