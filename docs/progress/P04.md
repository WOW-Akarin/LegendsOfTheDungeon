## 计划 Gate

1. 非测试生产项目生成 XML documentation file；CS1591 由 `TreatWarningsAsErrors=true` 升级为阻断错误。
2. Test 项目不属于对外生产 API，自动 XML 文档 Gate 不适用。
3. 生成/第三方项目可显式例外，但必须声明：
   - `LegendsOfTheDungeonDocumentationGateExempt=true`
   - `LegendsOfTheDungeonDocumentationGateExemptionKind=Generated|ThirdParty`
   - 非空且可审计的 `LegendsOfTheDungeonDocumentationGateExemptionReason`
4. 自测脚本现场生成夹具，至少证明：
   - 有完整中文 XML 注释的 Public API 可构建；
   - 缺失 XML 注释被 `CS1591` 拒绝；
   - 合法生成/第三方例外可构建；
   - 缺失理由或非法例外类型被自定义 MSBuild Gate 拒绝。
5. 中文语义、复杂逻辑设计说明、AC Commit/File/Function 由人工 Review Checklist 审查。

## 中文语义人工 Review 样本

### 合格样本

P04 正例 `DocumentedApi.ValidateNonNegative` 的 XML 注释说明了：

- 职责：验证非负输入并原样返回；
- 前置条件：输入必须大于等于零；
- 线程/执行上下文：不跨线程；
- 状态影响：不执行 I/O、不修改共享状态；
- 失败语义：负数抛出 `ArgumentOutOfRangeException`；
- 参数与返回值：均有明确语义。

结论：**PASS**。这类注释能解释契约，而不是只重复方法名。

### 应拒绝样本

若同一方法只写：

> “执行验证方法，返回结果。”

即使含中文，也没有说明非负前置条件、异常、线程/状态副作用与返回语义。按 [中文注释与文档质量 Review Checklist](../reviews/DOCUMENTATION_QUALITY_REVIEW.md) 必须退回。

结论：**FAIL（人工语义 Review）**。因此 P04 明确证明“有中文”不等于通过。
