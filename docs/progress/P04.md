## 计划 Gate

1. 非测试生产项目生成 XML documentation file；CS1591 由 `TreatWarningsAsErrors=true` 升级为阻断错误。
2. Test 项目不属于对外生产 API，自动 XML 文档 Gate 不适用。
3. 生成/第三方项目可显式例外，但必须声明：
   - `LegendsOfTheDungeonDocumentationGateExempt=true`
   - `LegendsOfTheDungeonDocumentationGateExemptionKind=Generated|ThirdParty`
   - 非空且可审计的 `LegendsOfTheDungeonDocumentationGateExemptionReason`
4. 自测脚本现场生成夹具，至少证明：
   - 有完整中文 XML 注释的 Public API 可构建；
   - 缺失 XML 注释被 `CS1591` 拒绝；
   - 合法生成/第三方例外可构建；
   - 缺失理由或非法例外类型被自定义 MSBuild Gate 拒绝。
5. 中文语义、复杂逻辑设计说明、AC Commit/File/Function 由人工 Review Checklist 审查。

## 实现落库

- `Directory.Build.targets`：非 Test、非例外项目自动启用 XML documentation file；验证例外种类/理由，并阻止生产项目用 `NoWarn` / `WarningsNotAsErrors` 绕过 `CS1591`。
- `eng/verify-documentation-gates.sh`：在 CI runner 现场生成 8 组夹具并执行正/负向自测。
- [中文注释与文档质量 Review Checklist](../reviews/DOCUMENTATION_QUALITY_REVIEW.md)：规定中文语义、复杂状态机/并发/算法/事务设计说明、AC Commit/File/Function 来源和新增中文说明文档人工审查。
- `.github/workflows/ci.yml`：新增 documentation quality gate 和独立 evidence artifact。
- [BUILD](../operations/BUILD.md)：记录统一命令和逃逸禁止规则。
