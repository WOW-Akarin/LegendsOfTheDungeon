## 目标和本轮交付

P11 交付 ConnectionFactory、Transaction、ParameterizedCommand、Migration、BulkLoader，必须通过真实 PostgreSQL 18 验证回滚、隔离、旧版本拒绝、幂等、超时结果未知和连接释放。当前批次先提供 Provider-neutral 的 ADO.NET 基础实现及最小 Unit。新建独立 Platform.Persistence 项目、Solution/P03 白名单、Unit 项目引用、锁文件，保留 Platform 不带业务 SQL 的边界。

- DatabaseConnectionFactory 拥有连接字符串，不向日志 API 泄漏；打开失败释放连接。
- ParameterizedCommand 校验安全参数名、DbType、重复参数并以 DbParameter 真正绑定值。
- PersistenceTransaction 的 Active/Committed/RolledBack/OutcomeUnknown/Disposed 状态严格区分；提交无法确认时不以失败补偿。
- 代码本轮未加入 Npgsql、PostgreSQL service、Migration、BulkLoader；不得宣称真实 DB 能力。
- 详细契约见 [Persistence 模块文档](../modules/PERSISTENCE.md)。
