## 范围、交付物与实际实现

本阶段提供独立 Platform.Persistence 生产 Assembly。只含 ADO.NET 连接、显式类型参数化命令、事务状态和 PostgreSQL 技术迁移账本；任何游戏业务 SQL 仍由未来模块 Infrastructure 持有。Solution、P03 清单、Unit 项目和锁文件已经同步。

1. DatabaseConnectionFactory：可注入 DbProviderFactory；打开失败释放连接，开启事务时要求显式 IsolationLevel；连接串不作为日志字段。
2. ParameterizedCommand：安全参数名、显式 DbType、重复名拒绝、DBNull 绑定。SQL 模板由调用模块自己审计，技术层不自动保证任意自由 SQL 文本都无法发生插值注入。
3. PersistenceTransaction：Active / Committed / RolledBack / OutcomeUnknown / Disposed；提交中异常和超时不能自动推断回滚；未提交退出时尝试回滚，始终释放连接。
4. PostgreSqlMigrationRunner：模块提供连续版本和固定 SQL；SHA-256 检查历史不可改，事务级 advisory lock、技术版本表和原子 DDL/DML 应用；不允许隐式降级或修补历史版本。
5. BoundedBulkLoader：只接受预先有界的参数化命令集合，执行前检查命令数量和参数总数；命令失败/取消回滚整批，成功执行不等于事务已提交。当前为通用有界批量命令，不是 PostgreSQL COPY 或无限流式导入。
6. P65.F 初始可控故障点：BeforeCommit / AfterCommit / AfterRollback。模拟真实 PostgreSQL 已完成提交却丢失确认，再用新连接查询持久化幂等账本；本阶段不宣称 P65 父阶段已完成。
