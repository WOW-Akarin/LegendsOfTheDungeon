## 几何约定

1. 世界坐标采用右手坐标系，`+Z` 向上。
2. 坐标与 Distance 单位为米。
3. Orientation 使用弧度；Yaw=0 指向 `+X`，正方向绕 `+Z` 逆时针朝 `+Y`。
4. 方向角 canonical 范围为 `[0, 2π)`。
5. 构造边界拒绝 NaN 和 ±Infinity。
6. default Position/Vector/Angle 是合法零值；与 Strong ID 的 empty sentinel 不同。
7. 零向量可以存在，但 Normalize 必须拒绝，因为方向未定义。
8. 算术结果若从有限输入产生非有限结果，显式抛出 OverflowException，不让 Infinity 进入领域值。
9. Bounds 为轴对齐边界盒，Min/Max 每个轴必须满足 Min ≤ Max；Contains 使用闭区间。
10. Geometry 不引用 Runtime/World，也不承载状态所有权。

## 实现落库

- `GeometryMath.cs`：有限数校验、有限算术、稳定三维长度和角度归一内部算法。
- `Position.cs`：三维米制位置、距离、闭区间范围、平移和位移向量。
- `Vector.cs`：长度、加减、缩放、Normalize、容差比较和 Yaw→单位向量。
- `Distance.cs`：非负米值与固定默认绝对容差 `1e-9 m`。
- `Angle.cs`：弧度输入归一到 `[0, 2π)`。
- `Transform.cs`：Position + Yaw，并可计算水平 Forward。
- `Bounds.cs`：轴对齐闭区间、Contains、最短距离和范围判断。
- `GeometryTests.cs`：零值、角度、右手坐标、距离、Bounds、NaN/Infinity、零向量、算术溢出和 Adapter-style JSON 回读。
